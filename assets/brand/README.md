# Herduck brand assets

Source of truth for the Herduck identity. Keep new artwork consistent with these files.

| File | Use |
| --- | --- |
| `../herduck-logo.png` | Main logo (transparent), README header, social cards |
| `../herduck-icon.png` | 256px app/favicon icon |
| `herduck-terminal.txt` | Full ASCII mark, ~70 columns. Startup/attach screen, `--version`, release notes |
| `herduck-terminal-mini.txt` | Compact ASCII mark, 20 columns. Onboarding, empty states, help header |
| `herduck-wordmark.txt` | Figlet wordmark plus tagline |

## Colours

| Token | Hex | Terminal | Use |
| --- | --- | --- | --- |
| Duck yellow | `#F5C33C` | 256-colour `220`, RGB `245,195,60` | ASCII mark, `duck` in wordmark, accents |
| Ink | `#1A1A1C` | default background | Dark backgrounds |
| Cloud | `#F4F4F2` | default foreground | Hood, `her` in wordmark, body copy |

## Voice

- Tagline: **Make AI work for you.**
- Secondary line (illustrations only, not a headline): *Good agents herd better humans.*
- Tone: calm, dry, slightly tired but competent. The duck is never excited.
- Keep copy short. One idea per sentence.

## Rules

- The ASCII marks render in a single colour (yellow on dark, or the terminal foreground). Do not
  colour individual glyphs.
- Do not stretch, rotate, or add drop shadows to the logo.
- The `</>` on the laptop is part of the mark; keep it.
