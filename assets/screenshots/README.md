# Screenshot capture notes

The seven images listed in [captures.json](captures.json) are native Ghostty window
captures of Herduck v0.1.0-alpha.4 on macOS. They were captured with a local
ScreenCaptureKit helper at the display's native scale and copied into this directory
without editing or re-rendering their pixels.
The manifest records their dimensions, capture times, and SHA-256 hashes.

The example follows LaunchDesk, a fictional product preparing for launch. Its
34 history records span seven project folders and six prepared Work groups; the launch
Work carries a saved plan (goal, three next steps, blocker) entered through `herduck work plan update`. The data
comes from an isolated demonstration profile. “First 100 users” is a plan target.

In the Agents image, the native Codex CLI contains a drafted review prompt, the
native Claude Code CLI opens a prepared launch conversation, and the billing pane
shows a real local `npm test` run with five passing tests. The screenshot illustrates
the workspace and its terminal interfaces; the prepared conversation is example content.
