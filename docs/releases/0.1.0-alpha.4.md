# 0.1.0-alpha.4 — Project progress and executable follow-ups

Source preview; release artifacts have not been published.

**打开 Topic 或 Project，了解 Agent 在做什么，并直接推进下一步。** 概览用最近的具体请求和
Agent 回应描述工作，提供“提交审核，通过后重新部署”这样的建议。点击 **推进此建议** 交给原 Agent
执行，忙碌时先排队；**查看会话** 打开上下文。父级分组保持高亮，已经填写的目标、下一步和卡点保留。

**Topics and folder Projects explain current work and offer concrete follow-ups.** Descriptions
come from recent local requests and Agent replies. Choose **Continue with this** to send a suggestion
to the original Agent, or **View conversation** to read its context. Saved Topic plans remain editable.

- Selected groups stay highlighted in detail and plan views, and when a child session is open.
- Natural descriptions replace the three-column overview. Session names remain as source labels.
- English and Chinese recommendations preserve the complete instruction and its execution conditions.
- Busy Agents receive queued follow-ups when idle; pending input can be cancelled. A blocked Agent
  opens for the user's answer. Repeated starts do not resend the same retained follow-up.
- History follow-ups use native resume; live follow-ups reuse their matching pane. Replaced or closed
  targets cancel pending input. Delivery records last for the current server's lifetime.
- Responsive layouts keep conversation navigation reachable. Session counts do not imply completion.
- `project.overview.get` and `project.followup.start/get/cancel` expose the same behavior through
  the public API and `herduck topic` / `herduck project` commands.
- Existing Catalog schema, Topic identities, cover conflict handling, and native session mappings are preserved.

See [Project overview](../project-overview.md) for controls, evidence scope, and API usage.
