# 0.1.0-alpha.3 — Topic covers

Source preview; release artifacts have not been published yet.

**Topic 封面：目标、下一步、卡住说明。** 点开 Topic，就能在对话列表上方看清这件事要做什么、
接下来做什么、卡在哪里。可以在界面编辑保存，重启后仍然保留；Agent 也能通过 CLI 或 socket API
读取和更新同一份封面。

**Topic covers: goals, next steps, and blockers.** Open a Topic to see an editable cover above its
conversations. Save a weekly goal, up to three next steps, and a blocker note; they survive restart.
People and Agents share the same data through the UI, `herduck topic` commands, and the socket API.

- Older Catalogs migrate automatically, preserving their conversations and Topic identities.
- Partial updates preserve other fields. The editor detects a newer edit before overwriting it.
- Covers remain accessible when automatic classification moves their conversations elsewhere.

Blockers are text in this version. Pane links, artifact lists, inferred goals, and a full task board
are future work. See [Topic covers](../topic-covers.md) for usage and API examples.
