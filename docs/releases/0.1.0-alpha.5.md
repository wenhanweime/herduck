# 0.1.0-alpha.5 — Quick Keys dock and Agent close

Published as GitHub release [v0.1.0-alpha.5](https://github.com/wenhanweime/herduck/releases/tag/v0.1.0-alpha.5) and npm `herduck@0.1.0-alpha.5` (`herduck@alpha`).

**底部快捷栏和 Agent 行关闭钮进入公开发布。** 终端列底部有一行 Quick Keys：Esc、Shift、中/英、Herduck、继续、Ctrl C、Cmd C、Cmd V、关闭。侧栏每个 Agent 对话第一行右侧有 ×，关闭该对话而不退出 Herduck。

**The in-app Quick Keys dock and per-Agent close control ship in the public alpha.** The dock sits under the terminal column. Default chips: Esc, Shift, 中/英, Herduck, 继续, Ctrl C, Cmd C, Cmd V, and 关闭. Each Agent row in the sidebar shows × on the first line to close that conversation.

- 关闭 on the dock detaches the current client; it does not quit the server.
- 中/英 and Cmd V run on the connected host (clipboard and input source), including server mode.
- Cmd C copies a selection or enters copy mode. Cmd chords that the terminal cannot report are refused instead of sending a bare character.
- Collapse the dock to reclaim two rows; `~/.config/herduck/quick-keys.json` stores custom chips.
- Wire protocol is 17 (`HostAction` / `HostActionResult`).
- Existing Topic covers, Work overview, and idle reclaim from 0.1.0-alpha.4 remain.
